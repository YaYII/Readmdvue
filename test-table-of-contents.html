📖 这是一个测试页面，用于验证 Markdown Reader 插件的目录功能

1. 介绍

这是一个用于测试目录功能的示例文档。当你安装并启用 Markdown Reader 插件后，应该能在页面左侧看到一个目录菜单栏。

1.1 主要功能

目录功能包含以下特性：

  • 自动提取页面标题
  • 层级缩进显示
  • 点击跳转到对应位置
  • 活跃标题高亮
  • 折叠/展开功能

1.1.1 设计理念

采用苹果 Liquid Glass 设计语言，提供现代化的视觉体验。

1.1.1.1 材质系统

使用半透明材质和背景模糊效果，营造深度感。

1.1.1.1.1 色彩系统

支持明暗模式自动切换，确保在不同环境下的可读性。

1.1.1.1.1.1 字体系统

使用系统字体栈，确保最佳的阅读体验。

1.2 使用方法

目录会自动显示在页面左侧，你可以：

  1. 点击目录项跳转到对应内容
  2. 使用折叠按钮隐藏/显示目录
  3. 滚动页面时查看活跃标题高亮

2. 技术实现

目录功能基于 Vue 3 + TypeScript 实现，具有以下技术特点：

2.1 架构设计

采用组件化架构，将目录功能封装为独立的 Vue 组件。

2.1.1 组件结构

主要包含以下组件：

  • TableOfContents.vue - 主目录组件
  • MarkdownRenderer - 渲染器
  • VueComponentManager - 组件管理器

2.2 性能优化

通过以下方式优化性能：

2.2.1 节流处理

对滚动事件进行节流处理，避免频繁计算。

2.2.2 懒加载

按需加载目录组件，减少初始加载时间。

3. 总结

目录功能为 Markdown 阅读提供了便捷的导航体验，结合苹果设计美学和现代前端技术，为用户带来优质的阅读体验。
