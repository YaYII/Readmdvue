🚀 使用方法

  1. 在浏览器中安装 Markdown Reader 插件
  2. 打开任意 Markdown 文件
  3. 点击设置按钮打开设置面板
  4. 在强调色选项中选择"自定义"
  5. 使用颜色选择器或预设颜色进行个性化定制
  6. 实时预览效果并保存设置
