🎨 强调色实时更新功能测试

📋 测试目标

验证用户在设置界面中选择不同强调色后，页面样式能够立即生效，无需刷新页面。这是用户体验的关键功能，确保设置变更的即时反馈。

🔧 测试步骤

步骤 1： 在浏览器中安装并启用 Markdown Reader Vue 扩展
步骤 2： 打开任意 Markdown 文件（如 GitHub 上的 README.md）
步骤 3： 点击页面右上角的设置按钮（⚙️）打开设置面板
步骤 4： 在"强调色"部分，依次点击不同的颜色选项：
蓝色 (#007AFF)
紫色 (#AF52DE)
粉色 (#FF2D92)
红色 (#FF3B30)
橙色 (#FF9500)
黄色 (#FFCC00)
绿色 (#30D158)
石墨色 (#8E8E93)
步骤 5： 观察每次点击后页面元素的颜色变化
步骤 6： 点击"确定"按钮保存设置

✅ 预期行为

  • 即时反馈： 点击强调色选项后，页面中的强调色元素应立即改变颜色
  • 影响范围： 以下元素应该反映新的强调色：
    • 标题文字颜色（h1, h2, h3, h4, h5, h6）
    • 链接颜色和悬停效果
    • 按钮背景色和渐变
    • 代码高亮中的关键字颜色
    • 引用块的左边框颜色
    • 表格标题背景色
    • 其他使用强调色的UI元素
  • 无需刷新： 整个过程不需要刷新页面或重新加载内容
  • 设置保存： 点击"确定"后，设置应该被保存到浏览器存储中
  • 持久化： 刷新页面后，新的强调色设置应该保持

🔍 故障排除

如果强调色没有立即生效：

  1. 检查控制台： 按 F12 打开开发者工具，查看 Console 是否有错误信息
  2. 检查DOM属性： 在 Elements 面板中查看 <html> 元素是否有正确的 data-accent 属性
  3. 检查CSS类： 确认根元素是否添加了对应的 accent-{color} 类
  4. 检查CSS变量： 在 Computed 面板中查看 --md-accent-primary 等变量是否更新
  5. 网络问题： 确认扩展与content script之间的消息传递正常

常见问题解决：

  • 扩展未激活： 确保在Markdown页面上扩展图标显示为彩色（已激活状态）
  • 权限问题： 检查扩展是否有访问当前页面的权限
  • 缓存问题： 尝试硬刷新页面（Ctrl+Shift+R 或 Cmd+Shift+R）
  • 扩展冲突： 暂时禁用其他可能冲突的扩展
