图表源码显示功能测试页面

测试说明

这个页面用于测试 Markdown Reader Vue 浏览器插件的图表源码显示功能。

请按照以下步骤进行测试：

  1. 确保已安装并启用 Markdown Reader Vue 浏览器插件
  2. 在下方的 Markdown 内容区域中，查找图表
  3. 点击图表下方的"查看源码"按钮
  4. 验证源码区域是否正确显示/隐藏
  5. 验证按钮文本是否在"查看源码"和"隐藏源码"之间切换
  6. 验证按钮样式是否有激活状态的视觉反馈

预期行为

  • 图表渲染：Mermaid 和 PlantUML 图表应该正确渲染为 SVG 或图片
  • 按钮显示：每个图表下方应该有一个"查看源码"按钮
  • 源码切换：点击按钮应该显示/隐藏图表的原始代码
  • 按钮状态：按钮文本应该在"查看源码"和"隐藏源码"之间切换
  • 视觉反馈：激活状态的按钮应该有不同的颜色和样式
  • 苹果风格：按钮应该具有 Liquid Glass 材质效果

故障排除

如果功能不正常，请检查：

  • 浏览器控制台是否有 JavaScript 错误
  • 插件是否正确加载和激活
  • 页面是否被识别为 Markdown 内容
  • 网络连接是否正常（图表渲染可能需要外部服务）
