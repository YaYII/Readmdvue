🎯 根本原因分析

目录工具栏按钮没有生效的原因是事件名称不匹配：

  • TableOfContents.vue 中触发的自定义事件名称与 main.ts 中监听的事件名称不一致
  • 导致点击按钮时无法正确触发对应的功能
  • 事件监听器无法捕获到正确的事件
🚫 修复前（错误的事件名称）
// TableOfContents.vue 中的错误事件名称 const openSettings = () => { const event = new CustomEvent('toc-open-settings') window.dispatchEvent(event) } const openExport = () => { const event = new CustomEvent('toc-open-export') window.dispatchEvent(event) } const openSearch = () => { const event = new CustomEvent('toc-open-search') window.dispatchEvent(event) } const toggleOriginalContent = () => { const event = new CustomEvent('toc-toggle-original') window.dispatchEvent(event) }
✅ 修复后（正确的事件名称）
// TableOfContents.vue 中的正确事件名称 const openSettings = () => { const event = new CustomEvent('showSettingsPanel') window.dispatchEvent(event) } const openExport = () => { const event = new CustomEvent('showExportDialog') window.dispatchEvent(event) } const openSearch = () => { const event = new CustomEvent('showSearchPanel') window.dispatchEvent(event) } const toggleOriginalContent = () => { const event = new CustomEvent('toggleOriginalContent') window.dispatchEvent(event) }

第一章：Vue.js 3.0 核心概念

Vue.js 3.0 是一个渐进式 JavaScript 框架，用于构建用户界面。它采用了全新的 Composition API，提供了更好的逻辑复用和代码组织方式。

1.1 响应式系统

Vue 3 的响应式系统基于 Proxy，相比 Vue 2 的 Object.defineProperty 有了显著的性能提升和功能增强。

1.1.1 ref 和 reactive

ref 用于创建响应式的基本类型数据，而 reactive 用于创建响应式的对象。

1.1.2 computed 和 watch

computed 用于创建计算属性，watch 用于监听数据变化。

1.2 组合式 API

Composition API 是 Vue 3 的核心特性，它提供了一种更灵活的方式来组织组件逻辑。

第二章：组件化开发

组件化是现代前端开发的核心思想，Vue 3 提供了强大的组件系统。

2.1 单文件组件

单文件组件（SFC）是 Vue 的特色功能，将模板、脚本和样式封装在一个文件中。

2.1.1 模板语法

Vue 使用基于 HTML 的模板语法，允许开发者声明式地将 DOM 绑定至底层组件实例的数据。

2.1.2 样式作用域

通过 scoped 属性，可以让样式只作用于当前组件。

2.2 组件通信

Vue 提供了多种组件间通信的方式，包括 props、emits、provide/inject 等。

第三章：状态管理

对于复杂的应用，我们需要一个专门的状态管理解决方案。

3.1 Pinia

Pinia 是 Vue 3 的官方状态管理库，提供了类型安全的状态管理。

3.1.1 Store 定义

使用 defineStore 函数可以定义一个 store。

Store 包含状态、getter 和 action 三个核心概念。
