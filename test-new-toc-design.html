🎯 新目录设计测试

悬浮触发 + 统一管理界面

🚀 新功能特性

  • 悬浮触发：鼠标靠近浏览器左侧 60px 位置时自动弹出目录
  • 统一管理：设置、导出、搜索、查看原始页面按钮都集成到目录顶部工具栏
  • 智能隐藏：提供隐藏按钮，可以手动关闭目录面板
  • 固定模式：支持固定目录面板，保持常驻显示
  • 折叠功能：可以折叠目录面板，只显示工具栏按钮
  • Liquid Glass：采用苹果最新的半透明材质设计

📋 测试说明

1. 将鼠标移动到浏览器窗口的最左侧边缘（60px范围内）

2. 目录面板应该会从左侧滑出，显示完整的目录和工具栏

3. 工具栏包含：设置、导出、搜索、切换原始内容、隐藏按钮

4. 点击隐藏按钮可以关闭目录面板

5. 支持固定和折叠模式切换

📖 第一章：设计理念

新的目录设计融合了苹果的视觉美学和微软的交互理念，创造出既美观又实用的用户界面。

1.1 苹果视觉美学

采用 Liquid Glass 材质系统，半透明效果能够反射和折射周围环境，动态适应明暗环境变化。

1.2 微软交互理念

遵循 Fluent Design System 的设计原则，通过光感、深度、动效、材质和缩放创造流畅的用户体验。

🎨 第二章：技术实现

目录组件使用 Vue 3 + TypeScript 构建，确保类型安全和高性能。

2.1 组件架构

采用组合式 API (Composition API) 组织代码逻辑，提高代码的可维护性和复用性。

// 目录组件核心逻辑 const { tocItems, isVisible, isPinned, isCollapsed } = defineProps<{ tocItems: TocItem[] onSettingsClick?: () => void onExportClick?: () => void onSearchClick?: () => void onToggleOriginal?: () => void }>()

2.2 悬浮触发机制

通过监听鼠标进入和离开事件，实现智能的悬浮触发效果。

2.3 状态管理

使用本地存储保存用户的偏好设置，包括固定状态和折叠状态。

🌟 第三章：用户体验

新设计大幅提升了用户体验，让文档阅读变得更加高效和愉悦。

3.1 响应式设计

完美适配桌面端、平板端和移动端，确保在不同设备上都有最佳体验。

3.2 无障碍支持

遵循 WCAG 2.1 AA 标准，支持键盘导航和屏幕阅读器。

3.3 性能优化

合理使用 v-memo、shallowRef 等优化手段，确保流畅的交互体验。

🔧 第四章：配置选项

提供丰富的配置选项，满足不同用户的个性化需求。

4.1 主题配置

支持浅色、深色和自动主题切换，完美适应用户的使用环境。

4.2 布局配置

可以调整目录面板的宽度、位置和显示层级。

4.3 交互配置

支持自定义触发区域大小、动画速度和悬浮延迟时间。

5.1 智能推荐

基于用户阅读习惯，智能推荐相关章节和内容。

5.2 协作功能

支持多人协作阅读，共享笔记和标注。

集成 AI 助手，提供智能摘要和问答功能。
